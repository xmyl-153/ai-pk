接入你自己的模型（3 步）

  1. 在项目根目录建一个 aipk.config.yaml（或跑 python -m aipk init 生成模板）；
  2. 填上你的 OpenAI 兼容网关，密钥放环境变量、不要写进文件；
  3. 保存后刷新本页，"接进来的真模型"就会出现在选手池里。
providers:
  mygateway:
    base_url: https://api.example.com/v1
    api_key_env: MY_GATEWAY_API_KEY   # 密钥从这个环境变量读
roster:
  - [mygateway, your-model-id, "我的模型", flagship]

设好环境变量再启动面板，例如 Windows：set MY_GATEWAY_API_KEY=sk-xxx 然后双击 启动对战台.bat。跑真模型会按你的网关计费。

参赛名单

点选手加入 / 移出名单（1 个也能跑，最多 8 个）。想接自己的模型？点右上角「＋ 接入我的模型」。

加权 · 你心里的"好模型"长什么样

改权重，排行榜实时重排—— 同一个模型，你更在意"能算对"还是"又快又省"，排名就会不一样。默认分高 ≠ 用起来好。

不花钱 —— 直接看本仓库 630 次真实运行（10 模型 × 63 题）的四维指标，每次随机抽一对，拖权重看排名怎么变
